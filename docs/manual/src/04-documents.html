Documents, Printing & Export

This chapter covers how to turn a finished shaft into paper: which tab produces which sheet, how to preview and tune a page before it prints, how to print directly or save a PDF, and how to produce blank write-in drafts, the consolidated sheet, and the Final schematic. It is written for the office user who produces the sheets. For how each sheet reads at the lathe, see Reading the Printed Sheets; for typing readings into the app, see Recording Shop Measurements.

The document set

Every job can produce six documents. Each one comes from its own tab in the editor's navigation menu, in this order:

Runout SheetRunout SheetThe shaft profile with numbered runout bubbles, recorded TIR (total indicated runout) values and high spots, and the optional coupling face end view.
Wear DocumentWear DocumentThe shaft outline and liner detail strips with wear areas, pit marks and measured Ø readings.

The Schematic tab is always available. The other five tabs stay greyed out (with the hint Add components first) until the shaft is built: at least one component and an overall length.

Where the output buttons are

Each tab carries three full-width buttons, always in the same order: Print <document> (filled, the main action), Preview <document> and Export <document> PDF. For example, the Runout tab shows Print Runout Sheet, Preview Runout Sheet and Export Runout Sheet PDF. A Blank draft (write-in) switch sits directly above the buttons.
Final runout sheet

Print comes first because most shops work from paper. The PDF file is the archive or email copy.

Previewing a sheet

The preview shows the real page: the same drawing code builds the preview, the printed sheet and the PDF file, so what you see is exactly what prints. Open it with the PDF preview icon on the Schematic or Final tab, or with the Preview … button on any other document tab.

Looking around the page

  • Pinch to zoom (from half size up to 8×). Drag to pan.
  • On the schematic and Final previews, double-tap the page or tap the Reset zoom icon to return to the whole page.
  • Turn the device sideways. Previews unlock rotation even on a phone that is normally held upright, so you can view the landscape sheet full width. Leaving the preview restores the normal orientation.
  • On the schematic preview, the floating Blank draft (write-in) chip at the top of the page switches the page between printed values and a write-in draft. The page redraws immediately.

The preview's top bar carries, from left to right: Back or Close preview, the title (for example Runout Sheet Preview), the PDF options icon, a labeled Print button, and the Export PDF icon.

The options panel never covers the page

Tap the PDF options icon (the slider icon) to open the PDF options panel at the bottom of the screen. The panel does not block the page:

  • The page moves into a strip pinned under the top bar and is cropped to the drawing itself, so blank margin takes no room. The panel fills the space below the strip.
  • You can still pinch and pan the strip while the panel is open. A zoom stays in place while the page redraws, so you can zoom in on a thread and watch it change as you move the thread sliders.
  • Close the panel with its ✗, by tapping the PDF options icon again, or with Back. While the panel is open, Back closes the panel first and leaves the preview up.
  • Opening or closing the panel resets the zoom, because the strip and the full page are fitted differently.

The undercut preview works the same way, including when the sheet prints on a portrait page: the strip takes the page's own shape. On a phone a tall portrait page may be drawn smaller to fit the strip; pinch to zoom in on it.

Live sliders, saved on release

Four sliders redraw the page while you drag: Shaft height, Body S-break, Liner & taper compression and Line thickness. During the drag the preview shows a quick lower-resolution page. When you lift your finger the value is saved and the page redraws sharp. Every other control (chips, checkboxes, and the thread, bubble and wear sliders) is saved when you tap it or let go, and then the page redraws. While a new page renders, the old page stays on screen and a small spinner turns in the top-right corner.

A drag never changes the job by itself. Only the release saves, so you can try a slider and drag it back without leaving anything behind.

The PDF options panel

Every document's options panel has the same layout. A short scope note sits at the top, then a Content row of chips, then a set of collapsible sections. Tap a section heading to open or close it. Some headings show the current value on the right (for example Lines & text shows the line weight, and Units shows Single or Dual · Inline).

App-wide settings and per-job settings

The scope note reads: Drawing settings here are app-wide — the same ones as Settings → Drawing — so every document follows them. Controls saved with this job say so. The panel holds two kinds of control:

App-wide (a look setting)
A shortcut to the same setting found in Settings. Changing it changes every document, on every job, from now on. Line thickness, fractions, shading, arrowheads, thread hatch and bubble size are all app-wide. There is no per-document copy of a look setting.
Saved with this job
Stored in the job file. It changes only this job, and a reopened job prints exactly as it did. These controls end their caption with Saved with this job: Shaft height, the liner and taper compression pair, Coupling face, and the wear sheet's strip and trace controls. Dual units is stored with the document too (its caption reads Saved with the document).

Blank draft is neither. It is never saved: it is off each time the app starts. See Blank drafts and Template mode.

The sections, in order

The sections always appear in the same order on every sheet, with the most-used first. A sheet leaves out any section it has nothing for. Shaft and Wear start open; the rest start folded, and they fold again each time the panel is reopened.

  1. Shaft: Shaft height, Body S-break, Keep liners and tapers proportional lengthwise, Liner & taper compression.
  2. Wear (wear sheet only): Components, Strip size, Trace depth exaggeration, Wear area shade, Taper–liner join.
  3. Runout bubbles: Bubble size, Bubble height.
  4. Thread (only when the shaft has a thread): Thread slant, Thread density.
  5. Lines & text: Line thickness, Dimension arrows, Fractions.
  6. Shade in Components: Bodies (with Explicit bodies only), Tapers, Liners, and on the undercut sheet Undercut drawing: line art (no shading).
  7. Measurement reference: Auto (closest end), AFT, FWD.
  8. Units: the Dual units switch and Dual-unit layout.

Blank drafts and Template mode

The app has two ways to produce a sheet for marking up by hand. They answer different needs.

Blank draft (write-in)

A blank draft prints the full drawing and form layout with every value left empty. Dimension lines still cut their break, which becomes a space to write in. The footer keeps every label — “Rate:”, “L.E.T.:” (large end of taper), “KW:” (keyway), “Customer:” and so on — each followed by a writing rule, and the lines are spaced wider to suit handwriting. Component names and S.E.T. (small end of taper) markers still print, because they identify parts rather than measure them.

What each document blanks:

DocumentOn the blank draft
SchematicDimension values, Ø callout values (write-in rule after the Ø), footer specs, job information and the side stamp. The Ø callouts chip decides whether the Ø leaders print at all.
Runout SheetJob information, OAL and TIR values. The bubbles stay; they are the write-in circles.
Wear DocumentJob information and OAL. Recorded wear is left out, giving a fresh inspection form; the profile and the liner detail strips still print.
Undercut DrawingJob information and OAL. Recorded undercuts are left out.
Consolidated SheetJob information, dimensions and recorded values.

To turn it on, tap the floating Blank draft (write-in) chip on the Schematic and Final previews, or use the Blank draft (write-in) switch above the Print button on the other document tabs. The Blank draft chip in each options panel is the same switch. How each blank sheet reads is shown in Blank drafts.

The data you recorded is never touched. Blanking changes only the printed page. A blank export adds _BlankDraft to its filename.

Blank draft is never saved. It is off each time the app starts, so a forgotten switch cannot quietly blank future jobs. Check the preview before you print a stack of forms.

Blank drafts are meant for the floor: reusing a similar shaft's layout for a new inspection, or keeping blank forms where phones aren't allowed. Every write-in break is sized for a mixed-number dimension written on a clipboard.

Template mode

Template mode prints the schematic as the shaft outline only, centered on the page, with no dimension rails, no labels and no footer. Turn it on with Settings → PDF Export Options → Template (shaft only).

  • It affects the schematic only, including the schematic file written by Export all. It does not reach the consolidated sheet or the Final schematic with runout bubbles.
  • Unlike Blank draft, Template mode is remembered. It stays on for every job until you switch it off.

If a schematic preview shows a bare outline with no dimensions, Template mode is still on. Switch it off before you print.

Printing and exporting

Print directly

  1. Tap Print <document> on the tab, or Print in the preview's top bar.
  2. In the Android print dialog, choose your printer (or Save as PDF).
  3. Print. The sheet is a single US Letter page, landscape — or portrait for an undercut drawing that prints in portrait (see Page).

A printed sheet and an exported PDF of the same document come from the same drawing step, so they are identical. The print job is named like the export file, so a print queue shows which job and drawing each sheet is; a blank schematic job adds “(blank draft)”.

Export a PDF

  1. Tap Export <document> PDF on the tab, or the Export PDF icon in the preview.
  2. The system file picker opens with a suggested filename. Choose a folder (on the device, an SD card, or a cloud drive such as Google Drive) and change the name if you want.
  3. Tap Save.

To have the file open in your PDF viewer as soon as it is written, turn on Settings → PDF Export Options → Open PDF after export (off by default). It applies to single exports; Export all never opens anything.

If something goes wrong while the sheet is being drawn, the app still writes a valid PDF that shows a “PDF export failed” page instead of a damaged or empty file. Re-export after fixing the cause.

File names

Every document's name starts from the same base as the saved job: Job #, Customer and Vessel joined by “ - ”, then the shaft side. A side of PORT, STBD (starboard) or CENTER is added; Other adds nothing. Blank job fields are skipped, and a character a file name cannot hold (such as / or :) becomes an underscore. Each document then adds its own ending.

The Consolidated Output tab

The consolidated sheet puts the inspection on one page: the schematic's dimension rails and spec footer, plus the runout bubbles and TIR values, the wear information (wear areas, pit marks, worn sections, and measured Ø values printed inside the profile), or both. The Schematic, Runout, Wear and Undercut tabs still produce their own standalone documents.

What's on the tab, top to bottom

  1. Sheet content: three chips. All three (the default), Schematic + Runout or Schematic + Wear. Leaving the bubbles out gives their space back to the shaft. The choice is not saved and returns to All three, so a forgotten partial choice can't quietly print less on a later job.
  2. Coupling face switch: the coupling end view, looking forward. It works only while the sheet carries runouts. It is saved with this job and shared with the Runout tab.
  3. Blank draft (write-in) switch, then Print Consolidated Sheet, Preview Consolidated Sheet and Export Consolidated Sheet PDF.
  4. Runout bubbles (folded; shown when the sheet carries runouts): the per-component station counts, the same rows as on the Runout tab. Runout sheet → opens the Runout tab for entering TIR values. See Runout.
  5. Shaft height and the liner and taper compression controls. These are the same per-job values the options panels carry.
  6. Worn sections: measured areas whose Ø values print inside the profile, with no line drawn through the numbers. Tap a row to edit it, or tap Add worn section. How to enter them is covered in Worn sections.
  7. Export all (below).

Export all

Export all writes the whole document package to one folder in a single step.

  1. Under Export all, untick any document you don't want: Consolidated, Runout, Schematic, Wear, Undercut. All five are ticked to start, except Undercut on a job with no undercuts recorded. Tick it anyway for a blank undercut write-in sheet.
  2. Tap Export all to folder….
  3. Pick a folder in the system picker and allow access.
  4. Read the result line, for example 5 of 5 PDFs written.
  • The consolidated file uses the Sheet content choice above it.
  • This tab's Blank draft (write-in) switch applies to every file in the batch.
  • The schematic in the batch follows Template mode and the Ø callouts choice.
  • Files take the names in the table above. If a file of that name is already in the folder, the system may add a number such as “(1)” instead of replacing it.
  • A document that fails still produces a file, with an error page inside. The result line says how many failed.
  • The Final schematic is not part of Export all. Produce it from the Final tab.

Print has no batch version: the Android print system runs one print job at a time. To print a whole package, export it to a folder, or print each tab in turn.

Shaft height and compression

A propeller shaft is long and thin: a 25′ shaft drawn to true scale across a sheet of paper would be a pencil line. So the drawing stretches the shaft's height and shortens its long plain runs to fit the page. The printed dimensions are always your typed values, whatever the drawing does to fit.

The default size

At 100% (Standard), the drawn height follows a straight line through two settings: a 4″ shaft draws 1/2″ tall and an 8″ shaft draws 1″ tall, so a 6″ shaft draws 3/4″. This is the proportion of a hand-drawn shop sheet. Change it in Settings → Drawing → Default drawing size (4″ shaft draws and 8″ shaft draws, from 1/4″ up to 1 1/2″). A larger shaft never draws smaller than a smaller one.

The Shaft height slider

Shaft height picks the drawn height directly, in inches on paper, from 1/2″ to 1 1/2″. Both limits are paper measurements. Shrink a large shaft to uncramp a crowded schematic, or grow one for more room to write in. A small shaft whose standard height is already under 1/2″ is never enlarged by the lower limit.

  • It is saved with the job, and one setting drives the schematic, runout, consolidated and wear sheets.
  • The runout and consolidated sheets also stretch the shaft to the full page width, so a short shaft can stand taller there than on the schematic. The inches the slider shows may therefore differ between the schematic preview and the runout preview for the same job.
  • On a shaft that can't reach 1 1/2″, the caption tells you the most this shaft reaches.
  • On the runout and consolidated sheets the page itself can set the limit: the dimension rails, the bubble rows, the coupling face and the footer all need room. The slider then stops at the tallest height that sheet really prints, and the readout and the Standard button show that height, never a taller one.
  • A blank write-in sheet never squeezes the shaft under 1/2″ to make room. Its write-in footer lines move a little closer together first.

Long bodies compress and print an S-break

To fit the page, long body runs are drawn shorter than true length. When a run is shortened below the Body S-break setting (half its true length by default), it prints the S-break symbol, the conventional sign that a length is not drawn to scale. Milder shortening prints a plain outline. A body run long enough to fill a large part of the page always breaks, even with the setting at Never. The S-break itself is the notice; no footer note repeats it.

  • Bare shaft always compresses. Auto (bare-shaft) sections are what gives up length first.
  • Explicit bodies start uncompressed. A body you add draws at true proportion, with no S-break. To let a very long explicit body compress, tick Compress on drawing on its card (see Compress on drawing). Bodies in older saved jobs keep compressing until you untick it.
  • Keyways and bolt rows stay true size. The stretch of a body around its keyway, or around a row of coupler bolt holes, never shortens, and the break is placed clear of it. The keyway's width scales with the drawn height, so it stays in proportion at any height; the bolt holes keep their true spacing.

Liners and tapers keep their proportions

Liners and tapers are what an inspection measures, so they get special treatment.

  • They shorten in length only and never print an S-break.
  • Tapers aim to keep at least 70% of their true length, and when the page is tight every taper shortens by the same factor. Two tapers of different lengths therefore never print the same size.
  • Liners and tapers shorten together, so they keep the same share of true length and read evenly against each other. Body runs between them keep their relative lengths too.
  • Keep liners and tapers proportional lengthwise asks for true length; Liner & taper compression sets how far they may shorten. Neither ever changes the drawn shaft height: they take whatever room the page has at the chosen height, and the line under the slider reports what they actually keep, for example Liners and tapers keep at least ~85% of true length.

The Final Schematic tab

The original schematic records the shaft as it came in. The Final schematic is the drawing the shaft leaves with, after the wear and undercut work has moved, lengthened or shortened a liner. The two are the before and the after of the same job, saved in the same job file.

Start the Final drawing

  1. Open the Final Schematic tab. (It is available once the shaft is built.)
  2. Read the short explanation, then tap Start from original schematic.
  3. The tab becomes the familiar shaft editor, under the banner Final drawing — the original schematic is untouched.

The Final drawing starts as an exact copy of the original. From then on the two are independent: edit the Final with the same cards, Add dialogs and OAL field as the Schematic tab, and nothing you change on one ever reaches the other. Moving a liner on the original later does not move it on the Final. Per-component print units apply to both drawings.

  • Runout readings, wear and undercut records stay with the original drawing. The Runout, Wear, Undercut and Consolidated Output tabs always print the original.
  • A job has one Final drawing. It is not carried into templates or mate duplicates.

Reset or discard

Open the ⋮ menu on the Final banner:

Reset to original
Replaces the Final drawing with a fresh copy of the original schematic. It asks first (Reset to original?), because it replaces every edit made on the Final tab; Undo brings them back.
Discard final drawing
Removes the Final drawing. It asks first (Discard final drawing?). The original is unaffected.

Both can be undone with the editor's Undo, like any other drawing edit.

Every Final sheet is marked so it can never be handed out as the original: “Drawing: Final” in the footer job block (or the runout sheet's header), a bold FINAL stamp beside the side stamp, and _Final, _Final_Runout or _Final_RunoutSheet in the file and print job name (see Reading the Printed Sheets).

If the Final drawing has overlapping components, the final runout sheet is blocked with the dialog Cannot print final runout sheet. Fix the overlap on the Final tab.

Drawing profiles

A drawing profile saves the whole drawing look under a name, so you can switch the whole shop's sheets between, say, a “Customer” look and a “Floor copy” look in one tap. Profiles live in Settings → Drawing → Profiles.

Save, apply, rename, delete

  1. Set up the drawing the way you want it (in Settings or on any options panel).
  2. In Profiles, type a name in Profile name (up to 40 characters).
  3. Tap Save. If the name already exists the button reads Update and overwrites that profile.
  • Tap Apply beside a profile to copy its look into your current settings. Apply doesn't ask first, so save the current look as a profile if you may want it back.
  • Tap the ⋮ (Profile options) beside a profile for Rename… or Delete…. Deleting a profile leaves the current settings as they are.
  • Up to 20 profiles can be saved.
  • Restore Drawing defaults puts the whole drawing look back to what a new install starts with, after a confirmation. Saved profiles, the theme and the preview colors are kept.

Profiles are device settings

A profile is a one-shot copy into this device's settings, nothing more. The app doesn't track which profile is “active”, and a job never remembers which profile drew it. Reopening a job prints it in whatever look the device has now. A profile applied on one tablet does not reach another tablet.

Per-job settings stay out on purpose. Shaft height and compression fit one particular shaft's proportions; they are not a look, so they belong to the job.
