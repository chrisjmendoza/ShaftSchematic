Settings Reference

Every setting the app offers, page by page, in the order Settings shows them: the default, the range, and what each one changes on screen and on paper. Use it to set the app up for your shop, or to find out why a sheet prints the way it does.

How Settings works

Open Settings from any of three places: the Settings button on the home screen, the Settings entry in the navigation menu, or the Settings item in the editor's More options menu. The main page is one long scrolling list divided into sections. Two rows on it open their own pages: PDF Export Options and Preview Colors. The back arrow returns you from either page to the main list.

Everything in Settings is app-wide: it belongs to this tablet or phone, not to a shaft. Change a setting once and every document you open or print follows it. The one exception is Units, which the open document remembers (see below).

Settings fall into two kinds:

Screen-only
Changes what you see in the app — the theme, the preview colors, the editor's grid and arrows. Never reaches a printed sheet.
Drawing
Changes the printed sheets — shaft height, S-breaks, arrowheads, fonts, shading. A few of these also restyle the on-screen previews; the tables say which.

Many drawing settings are also on the PDF options panel that opens over each document's preview. Where a table says “Also on the PDF options panel”, the two controls are the same single setting reached from two places: move it on the panel and Settings shows the new value, and the reverse. The panel exists so you can tune the look while watching the sheet change. See The PDF options panel.

A slider in Settings saves when you let go of it, not while you drag. Chips and switches save the moment you tap them. Each slider has a Default (…) or Standard (…) button beside its title; the button greys out while the setting is already at its default.

Units

Settings → Units — the unit every new drawing starts in, and how values are shown and typed in the open document.

SettingDefaultWhat it does
Millimeters | InchesMillimetersEvery new drawing starts in this unit, so a metric shop sets it once. While a drawing is open the chips also switch it: every field, badge, drawing and printed sheet shows values in the chosen unit. Inch fields accept fractions such as 3 1/2. The choice is saved with the document, so a shaft reopens in the unit it was drawn in, and changing the setting later never flips a saved job.

Switching units never changes a number; see Millimeters and inches.

To print one component in a different unit from the rest of the shaft — a metric thread on an inch shaft, for example — switch on Per-component units under Drawing (below).

Drawing

Settings → Drawing — what every printed sheet looks like. These settings apply to every document; a document never stores its own copy of them. The section opens with component names, runs from shaft size, through the wear document, to lines, threads and text, and ends with four switches that reveal extra controls in the editor.

Component names

Component names on drawing (on by default) is the default for every component's Show name on drawing switch. A card that has not been set follows it, and says so under its switch: Following Settings → Drawing → Component names. A card you set yourself keeps its choice either way: switched on there, the name prints even with this off; switched off, it stays hidden even with this on. Turn it off if your drawings normally go out without names and you only name the odd section. The same setting is the Component names chip on the schematic's PDF options.

Shaft size and S-breaks

SettingDefaultWhat it does
Default drawing size: 4″ shaft draws0.5″How tall a 4″ shaft draws on paper at 100% Shaft height. Slider 0.25″ to 1.5″ in 1/16″ steps.
Default drawing size: 8″ shaft draws1″How tall an 8″ shaft draws. Same range and steps. Every other diameter follows the straight line through the two points; the line under the sliders shows the result live (for example, Example: a 6″ shaft draws 0.75″.). Standard (0.5″ / 1″) restores the standard pair.
Body S-breakbelow 50%How much a body run must be shortened before it prints the S-break symbol. Slider from Never to Always in 5% steps; the readout shows Never or below 50% (or your value). Default (50%) resets it. Also on the PDF options panel (schematic, runout and consolidated sheets).

If you set the 8″ value below the 4″ value, a red warning appears and drawings flatten at the 4″ height, because a larger shaft never draws smaller than a smaller one. The per-job Shaft height slider works on top of this default, and a very long body run breaks at every S-break setting, Never included. See Shaft height and compression.

Wear document

These three shape the wear document's detail strips. They change the drawing only; printed Ø values never change.

SettingDefaultWhat it does
Wear depth exaggeration25%The default for how deep the worn-profile trace draws, as a fraction of the liner radius. Slider 5% to 25% in 1% steps; Default (25%) resets it. A job can set its own value with Trace depth exaggeration, whose Save as default writes back here (see The worn-profile trace).
Wear area shade16%Grey of a measured wear area in the detail strips. Slider 5% to 35% in 1% steps. The range stops where a heavier grey would bury the pit marks drawn into the band, printed or by hand. Also on the PDF options panel (wear sheet).
Taper–liner join3″A taper and the liner beside it share one detail strip. This is how much bare shaft may sit between them before the strip breaks the gap instead of drawing it true. Slider 0″ to 12″ in 1/2″ steps (10 mm steps when working in millimeters). At 0 any gap breaks; touching components always draw joined. Also on the PDF options panel (wear sheet).

Lines, threads and text

SettingDefaultWhat it does
Dimension arrowsSmallArrowhead size on the dimension rails: Small, Medium or Large. Heads point inward unless the span is too narrow to hold both. A smaller head lets more values sit inside the dimension line. Also on the PDF options panel (schematic and consolidated sheets).
Thread slant3×How far the thread hatch leans. It follows each thread's own pitch; 1× is the true crest angle and higher values lean it further so the thread reads at print size. Slider from 1× true to 10× in 0.5× steps; Default (3×) resets it. Restyles the on-screen previews too. Also on the PDF options panel (Thread section, shown when the shaft has a thread).
Thread density50%How many of the thread's crests the hatch draws. Slider from Sparse (15%) to 100% true (every crest at true pitch) in 5% steps; Default (50%) resets it. Fine threads stay at a legible minimum spacing. Also on the PDF options panel (Thread section).
Output fontStandardThe typeface every printed sheet is set in: Standard, Condensed, Serif or Monospace. Each chip is labeled in its own face. Condensed fits more values inside the dimension line; Monospace lines digits up in columns. Paper only — app screens are unaffected. Settings only; it is not on the PDF options panel. A device that lacks a face prints in Standard.
FractionsDiagonalHow a fraction is set: Stacked (numerator over denominator with a bar, the shop-ruler fraction), Diagonal (raised numerator, slanted divider) or Plain (3/16 on one line). Applies to the on-screen sheets and the printed sheets alike. Also on the PDF options panel (Lines & text section).
Dual-unit layoutInlineHow a value printed in both units is set: Inline puts both on one line — 1 1/2″ [38.1 mm]; Stacked puts the second unit under the first. Stacked is about half as wide, so more values sit in the dimension line; a sheet too tight for the taller value falls back to Inline for the whole sheet. Has an effect only on a document with dual units on. Also on the PDF options panel (Units section, greyed out while that document's dual units are off).

Changing the font, fraction style or dual-unit layout never makes text collide. Every rail break and label is measured from the text as it will actually print.

Switches that reveal extra controls

The last four rows in Drawing are switches. Most shops never need the controls behind them, so they stay hidden until you switch them on. Switching one off again only hides the controls — anything you already set with them keeps printing.

SettingDefaultWhat it does
Per-component unitsOffLets one component print in a different unit from the document. Reveals a Prints in: in | mm chip at the foot of each body, taper, thread and liner card, and a Keyway in: chip with the keyway fields on body and taper cards and in the Add Body and Add Taper dialogs. Prints in: changes printing only — you still type in the document unit. Keyway in: sets the unit you type the keyway in as well as the unit it prints in, so a 20 × 12 mm keyway is entered as millimeters, not as converted decimals.
Dual-unit displayOffPrints both units on the sheets, for example 1 1/2″ [38.1 mm]. Flipping it switches dual units for the document that is open; each saved job reopens with its own choice. To change one job, use the Dual units switch in the Units section of its PDF options panel.
Liner shouldersOffReveals the stepped-shoulder fields (length, Ø, edge radius) on the liner card and in the Add Liner dialog. A liner that already has shoulder values keeps its controls and always draws its shoulders, whatever this switch says. See Liner shoulders.
Unit converter in Add dialogsOffAdds a mm ↔ in converter button to the title of every Add dialog, for converting a value from a print in the other unit before you type it. The Unit converter in the side menu's tools is always available either way.

Profiles

Settings → Drawing → Profiles — save the whole drawing look under a name and switch between looks in one tap. App-wide, like the settings they hold.

Type a Profile name and tap Save (it reads Update when the name exists) to keep the current look; tap Apply beside a profile to copy it back into your settings; use ⋮ → Rename… / Delete… to manage it. Restore Drawing defaults puts every setting a profile stores back to its new-install value, after the Restore Drawing defaults? confirmation. Up to 20 profiles, names up to 40 characters. What a profile captures, and why per-job values stay out, is in Drawing profiles.

PDF Export Options

Settings saved with the job

Some controls that look like settings belong to one job and travel with it, so a reopened shaft prints exactly as it did. You will not find them in Settings: Shaft height (1/2″ to 1 1/2″), the liner and taper compression pair, Dual units, Trace depth exaggeration, the wear strip choices, Coupling face and Cut depth exaggeration. They live on each document's PDF options panel and its tab, and their captions say so (see The PDF options panel).

The Bubble size and Bubble height sliders on the runout and consolidated panels are the reverse case: app-wide settings with no Settings row, because they only mean something on a runout drawing. See The PDF options panel for every panel control.

Achievements

Settings → Achievements — Enable Achievements (default off) turns on the app's unlockable milestones; View Achievements opens the list and stays greyed out until achievements are enabled.

Data

Settings → Data — getting your shafts off the device and back again, and sending a log to support. Saved shafts otherwise live inside the app; these rows are how you protect them against a lost, broken or replaced tablet.

RowWhat it does
Back up all shafts…Saves every saved shaft into one zip file at a location you choose — Drive, Downloads, an SD card. The suggested name is ShaftSchematic-backup- followed by the date.
Restore from backup…Imports shafts from a backup zip. It never overwrites: a shaft identical to one you already have is skipped, and a different shaft with the same name comes in as (restored) after its name.
Mirror saves to folderOff until you pick a folder. From then on every shaft you save is also copied there, so your off-device backup is always current. Deleting or renaming a shaft in the app does the same in the folder. The row shows the folder and the result of the last copy; Stop turns mirroring off. A copy that fails never interrupts the save — the row says so, and your saved shaft is fine.
Mirror all nowShown once a folder is picked. Copies every saved shaft to the folder now, catching up anything saved before you picked it, and reports how many went through.
Restore sample shaftsRe-adds the bundled example shafts to Saved. It won't overwrite your files.
Share diagnostic logsOpens your email app with the app's event log attached, for sending to support when something goes wrong.

Point Mirror saves to folder at a cloud-synced folder (Google Drive, for example) and tap Mirror all now once. After that, every save is backed up with no further steps.

The diagnostic log records events, never the values in your drawings; see Sharing diagnostic logs.

Help & FAQ and About

Settings → Help & FAQ opens the in-app help, with search at the top. The Runout, Wear, Undercut and Consolidated Output tabs also open it directly at their own topic. This manual opens from the User manual card at the top of Help (see Help & FAQ).

Settings → About ShaftSchematic shows the app version under the row. The About page lists the app version and package name, and the note that all geometry is stored in millimeters. Quote the version when you contact support.

A Developer Options row can appear at the end of the list. It exists for support use; nothing on it is needed for shop work, and it never changes a drawing.
