The Shaft Editor

How to build a shaft in the editor: starting a job, setting the overall length, adding and editing components, working with bare shaft, clearing overlaps, undoing mistakes, and reusing work through templates and mate duplicates. This chapter covers the workflow; the field-by-field detail for each component is in Components Reference.

The editor at a glance

The editor is the Schematic tab. From top to bottom it shows:

Title strip
The document name, or Untitled draft for a job that has never been saved. An asterisk after the name means there are unsaved changes. Tap it to name or rename the job (see Naming the job).
Toolbar
Shaft Editor, with the navigation menu button, History, Project information, New, Open, Save, PDF preview and More options (see The title strip and toolbar).
Preview
A live drawing of the shaft, AFT on the left and FWD on the right.
Overall length
The Overall Length field.
Components
The + Add Component button, any shaft-wide warnings, and the carousel of component cards, one card per component, in order along the shaft.

The other document tabs, the calculators, Help and Settings are in the navigation menu (see The navigation menu). On a tablet held wide, the editor splits into two panes; everything works the same way in either layout.

Starting a job

Start from the home screen with New Drawing, Start from Template (see Templates) or Open…, or continue one of the Unsaved drafts listed above them (see The home screen). Inside the editor, the toolbar New and Open buttons do the same. If the current job has unsaved changes, the app asks first: Save, Don't save (the autosave draft still keeps the work), or Cancel.

  1. Tap New Drawing.
  2. Tap Project information on the toolbar and fill in the job details.
  3. Check the unit (a new drawing takes the one set under Settings → Units; see Units for the job).
  4. Type the Overall Length and tap the green ✓.
  5. When the app asks for the Shaft diameter, type the bare-shaft diameter and tap Set (see The overall length).
  6. Add the components with + Add Component, AFT end first is easiest.
  7. Tap Save and confirm the suggested name.

The sheet date is not typed: every sheet prints the date it was made. Nothing on the sheet takes effect until you tap Save; Cancel throws the edits away. If you swipe the sheet closed with edits pending, the app asks Save changes? and offers Save, Keep editing or Discard.

Fill in the project information before the first save. The suggested file name is built from it, and the mate duplicate copies it across.

Naming the job

A job is named when it is first saved. Tap Save (or the title strip) on an unsaved job and the Save Drawing screen opens with a File name already suggested: job number, customer, vessel and side joined with dashes, for example “J-2214 - Acme Marine - Northern Star - PORT”. With no project information, the suggestion is “Shaft_” followed by the date and time. If the name matches a saved shaft, the screen says so and asks before overwriting.

Once a job is saved, tapping the title strip opens Rename saved shaft. A name another saved shaft already has is refused, and the reason shows under the name field (A saved shaft named ‘…’ already exists.); change the name and tap Rename again. If you save a job and its project information now suggests a better name than the one it was saved under, a message offers Rename; it never renames over another saved shaft.

Unsaved drafts on the home screen are listed by the name the job would be saved under, so three drafts are told apart by job, not just by age. A draft with no project information shows as Untitled draft.

Units for the job

A new drawing starts in the unit chosen under Settings → Units (Millimeters or Inches), so set it once for the shop and every new drawing follows it. The job remembers its unit from then on: it reopens the way it was drawn, and changing the setting later never flips an open or saved job. While a job is open, the same chips switch how it is shown and typed. Inch fields accept fractions: type “3 1/2” or “150 3/4”. Some keyboards answer a number field with a number pad that has no / key, so while you type in an inch field a small grey fraction button — an n over a bar over a d — sits at the right end of the field. It types the fraction bar (/): tap it where the bar goes (10, space, 1, /, 4). A hyphen works as the separator too: “10-1/4”.

Switching units never changes a dimension (see Millimeters and inches). To print one component in the other unit (a metric thread on an inch shaft), see Prints in: in | mm.

The overall length

The Overall Length field holds the shaft's OAL (overall length), end to end. It is always the number you type; nothing in the app sets, grows or shrinks it for you.

Entering and changing it

  1. Tap the Overall Length field. A shaft with no length yet shows 0; the 0 clears when you tap in.
  2. Type the length.
  3. Tap the green ✓, or the keyboard's Done key. Tapping away from the field after changing it also accepts the new length.

The green ✓ and red ✗ appear beside the field only while you are changing the value. The ✗ puts back the stored length and changes nothing. The drawing does not follow your typing digit by digit; it changes once, when you accept the new length, so an edit from 368 1/2″ to 367 3/4″ never passes through a 36″ shaft on the way.

  • An empty field changes nothing. Clear the field to retype it, change your mind, and the stored length comes back. You cannot zero a shaft by accident.
  • No length yet is not an error. Until an OAL is typed, the preview draws the shaft out to its last component and no “past the end” warnings appear. The other document tabs wait for a length.
  • Components past the end are allowed. If a component runs past the OAL, the field turns red as a warning. Nothing is rejected or trimmed; fix whichever number is wrong.

When a thread is excluded from the OAL, a read-only line under the field, Dimensioned OAL, shows the span the sheet's OAL dimension actually covers.

The shaft diameter prompt

On a new drawing, the first time you accept an overall length the app asks for the Shaft diameter: “What is the bare-shaft diameter? Components you add will sit on a shaft of this size.” Type it in the drawing's unit (fractions are fine) and tap Set; every stretch of bare shaft takes that diameter. Tap Skip to leave it for later. The question comes once per drawing: it is not asked again after a Skip, and never when you open a saved job or start from a template. You can change the diameter at any time on a Body (auto) card (see Bodies and bare shaft).

What moves when the OAL changes

Each taper, liner and coupler bolt slot is measured from the end you chose for it with its AFT | FWD chips. When the OAL changes:

  • Components measured from AFT stay exactly where they are.
  • Components measured from FWD keep their distance from the FWD end and move with it. A FWD taper set flush with the end stays flush.
  • A thread excluded from the OAL stays hung off its end of the shaft.
  • Bare shaft fills whatever gap opens or closes. An explicit body keeps its own start and length, so after a big change check it against the new end.

When an OAL change moves anything, a message at the bottom of the screen says what moved, how far and which way, for example OAL 234 3/16": moved FWD Liner 4 13/16" aft (measured from FWD). Up to two parts are named, then a count (+1 more). Tap Undo on the message to put the old length back with everything it moved. Nothing moved, no message.

This is the way the print reads at the lathe: a FWD taper dimensioned from the FWD face is still dimensioned from the FWD face after the shaft is shortened. Only the overall length on the sheet changes.

Adding components

Every component is added from the one full-width + Add Component button under the overall length. It opens the Add Component chooser:

ChoiceThe Add dialog asks for
BodyStart, Length and Diameter; optional face finish (Square or Blend) and seal areas at each end; an optional keyway behind the Keyway checkbox.
LinerMeasure From: AFT | FWD, start from that end, Length, Outer Ø; shoulders when they are switched on in Settings.
TaperMeasure From: AFT | FWD, start from that end, Length, S.E.T. (small end of taper) Ø, L.E.T. (large end of taper) Ø, rate (Auto or Manual), and an optional keyway.
ThreadStart (or AFT | FWD end when the thread is not counted in the OAL), Imperial (TPI — threads per inch) or Metric (mm, a designation such as M20×2.5), diameter and pitch, Length, optional thread relief, and Include thread in OAL.

Every field and option is described in Components Reference. Tap Add to place the component, or Cancel. The new component is selected straight away: it highlights in the preview and the carousel moves to its card.

If you press Back or tap outside a dialog you have already typed in, or changed a chip or switch in, the app asks first, for example Discard this liner?. Keep editing takes you back with everything as you left it; Discard closes the dialog and adds nothing. A dialog you have not touched closes straight away, and Cancel always closes without asking. The worn-section editor on the Consolidated Output tab asks the same way.

What the dialog fills in for you

  • Start is pre-filled at the end of the last taper, thread or liner, so working AFT to FWD needs little typing. A new body is pre-filled to run from there to the OAL.
  • Sizes are pre-filled from the last component of the same kind you added or edited in this session, or from the opened drawing. A run of identical liners takes one diameter typed once.

These are suggestions in the box. Whatever you type replaces them, and the app stores exactly what you typed.

When the Add button is greyed, or asks first

  • Add stays greyed until the required values are entered: a start, a length above zero, and a diameter.
  • A liner that would overlap another liner, or a thread that would overlap another thread, shows Overlaps and the other card's name (for example Overlaps AFT Liner) under its start field and cannot be added there.
  • A liner, taper or thread that would overlap a different kind of component shows the same line in red under its start field, naming the part (for example Overlaps FWD Taper), whichever end you measure from. Add stays live and asks first (next point).
  • A liner or taper measured from FWD whose length would carry it past the AFT end shows Runs past the AFT end of the shaft and cannot be added there.
  • A number a field needs above zero (a length, a diameter, a bolt spacing) shows Must be > 0 when it is 0, and a bolt Count that is not a whole number of 1 or more shows Must be a whole number ≥ 1. Add stays greyed until it is fixed.
  • A thread placed between two components shows Thread must be at a shaft end, not between components.
  • A liner, taper or thread that would overlap a different kind of component, or fall outside the shaft, opens Add Anyway? with the reasons listed, for example Overlaps FWD Taper or Falls outside shaft span. Tap Add Anyway to add it regardless, or Cancel to go back and fix the numbers. An overlap added this way blocks printing until it is cleared (see Overlaps and the print gate).

Bodies never warn about overlap. They are the shaft's base stock and are meant to run under liners and up to tapers (see Bodies and bare shaft).

The card and the dialog always match

Every control on a component's card that changes its shape, position or a value also appears in its Add dialog, under the same conditions, so nothing is out of reach at add time. The only exceptions are a few drawing-only switches, such as Show Ø on drawing, which are on the card alone (see Per-component drawing switches).

The preview

The preview draws the shaft as you build it: bare shaft, tapers, threads with their hatching, liners, keyways and bolt holes, at the same proportions the schematic will use.

  • Tap a component to select it. It highlights and the carousel jumps to its card.
  • Tapping empty space does nothing. The preview is for looking and selecting only; components are added from + Add Component.
  • Shading. A body, taper or liner that will print shaded on the sheets is filled in the preview; one that will print plain is an empty outline. The fill follows the Settings shading choices and each card's Shade on drawing switch, so you can see what will print grey before you print.

A grid behind the shaft, the selection highlight and ◀ ▶ arrow buttons on the carousel are set under Settings → Editor Screen (see Editor Screen).

The preview's colors are set under Settings → Editor Screen → Preview Colors. They change the screen only; printed sheets are always black ink on white.

Editing in the carousel

Under the Components heading (Swipe to select), the carousel holds one card per component, in physical order from AFT to FWD, with bare-shaft cards in their places between them. Swipe left or right to move along the shaft; the card you land on is selected and highlights in the preview. When a document opens, the AFT-most card is selected.

Card names

Each card is titled with a name worked out from its place on the shaft: Body #1, AFT Taper, FWD Thread, AFT Liner, MID Liner #2, and so on (see Component names). Bare shaft shows as Body (auto). To give a component your own name, tap its title or the pencil beside it (Rename), type, and tap Done. Clear the name to go back to the automatic one.

How values are saved

A value on a card is saved when you leave the field, either by tapping elsewhere or tapping Done. It is not saved on every keystroke. Tapping into a field and leaving without changing it does nothing at all.

Each card has a Save button at the bottom. It is greyed while everything on the card is saved and lights up while a field holds a value you have typed but not yet saved. Tap it to save that value.

Chips, checkboxes and switches do not take the keyboard's focus, so typing a value and then tapping a chip can leave the typed value unsaved in its field. If Save is lit, tap it.

A value the field cannot accept, such as a length of zero (Must be > 0), a negative start (Must be ≥ 0), or text that is not a number, shows a message under the field and is not saved; the field goes back to the stored value.

A typed value is never rounded, snapped or adjusted; bare shaft fills the gaps around it. See What you type is what prints.

Deleting a component

Tap the red trash icon (Remove) in the card's title row. The component is removed at once and a message such as Taper deleted appears with Undo; tap it to bring the component back. A deletion can also be undone later from History. Bare-shaft cards have no trash icon: bare shaft goes away when something else covers it.

Bodies and bare shaft

Every stretch of the shaft you have not covered with a component is drawn as bare shaft, so the drawing is always one continuous piece. Bare shaft is filled in automatically and shows in the carousel as a Body (auto) card. You never need to add bodies just to join components together.

Setting a bare-shaft diameter

On a Body (auto) card, Start and Length are greyed: they come from the components on either side. The Diameter field is live. When the shaft has more than one section of bare shaft, accepting a diameter asks Apply diameter to…:

  • This section sets the diameter of the section you are on only. Each section can take its own diameter, so a shaft can step between liners without a single explicit body, and changing one section never changes another.
  • All auto sections sets the bare-shaft diameter for every section together, and clears any section that had a diameter of its own.
  • Cancel changes nothing, and the field shows the stored diameter again.

With only one section of bare shaft there is nothing to choose: the diameter you type is the shaft's. Clear the field, or enter 0, to let a section take its diameter from its neighbors again.

A section's own diameter goes with it. If you delete the component that separated it from the section before it, the two join and the joined run keeps the earlier section's diameter; add a component later that splits it again and the new section takes the shaft's diameter, not the old value. Undo brings the old value back. Moving or resizing a component, or changing the overall length, never loses one: a section squeezed out by a resize gets its diameter back when the room returns.

If two sections with different diameters are joined (because the component between them was deleted), the joined section takes the AFT section's diameter. The FWD section's diameter is kept in reserve and comes back if the two are split again.

The auto card also carries Show bare-shaft Ø on drawing (one switch for all bare shaft) and the face finish and seal area controls; see Bodies.

Making a body explicit

An explicit body is a body you control: fixed start and length, its own diameter, a keyway, a name of its own. To turn bare shaft into one:

  1. Swipe to the Body (auto) card.
  2. Tick Explicit body.

The card becomes a body card holding the section's current start, length and diameter, now editable. You need an explicit body to put a keyway in a plain end section, or to lock a section's size so it no longer follows its neighbors. You can also add one directly with + Add Component → Body.

Making a body automatic again

Untick Explicit body on the body card. The app asks Make body automatic?, warning that the body's stored size will be replaced by bare shaft, and adds Its keyway will be removed too. if it has one. Tap Make automatic to confirm, or Cancel.

How bodies behave around other components

  • Adding a taper, liner or thread over a body splits it into separate body cards, one each side.
  • Deleting that component joins the pieces back into one body, unless something else still sits in the gap.
  • A body with a keyway is never split. It stays one card with its keyway intact; the drawing still shows the component over it.
  • A body may run under a liner or up against a taper. That is how a shaft is built, so it is never reported as an overlap. The drawing shows the liner or taper and trims the body around it.
  • An explicit body never merges with its neighbors. Two explicit bodies of different diameters stay two bodies; a shortened explicit body leaves bare shaft beside it.

Overlaps and the print gate

A shaft cannot have two solid features in the same place. The app treats these as collisions:

  • a taper overlapping another taper, a thread, or a liner;
  • a thread overlapping another thread or a liner;
  • a liner overlapping another liner.

Components that only touch end to end do not collide. Bodies and bare shaft never collide with anything, coupler bolt slots never collide (they are drawn reference holes), and a thread excluded from the OAL sits outside the shaft and is not checked.

How a collision is shown

  • Each component involved carries an error strip on its card naming what it overlaps, by the title on that card — Overlaps FWD Taper, or a list such as Overlaps AFT Liner, FWD Taper. A name you gave a component is the name used.
  • The warnings banner above the carousel lists each overlapping pair by name, for example FWD Liner overlaps Body size transition taper, and the drawing shows the stretch they share as a red band.
  • The PDF preview button on the toolbar is greyed. Tapping it names the same pair: Can't export: FWD Liner overlaps Body size transition taper.

Printing, preview and export are blocked because a sheet with two features in one place cannot be machined from. A shaft with no components at all is blocked the same way, with the message Please add at least 1 component before export is active.

Fixing a collision

  1. Tap the overlap line on the warnings banner to jump to the first part it names (or swipe through the carousel to a card with the error strip).
  2. Correct its start or length (or its partner's) so the two no longer share any length.
  3. When the strip clears on every card, the PDF preview button comes back.

A thread placed between two components rather than at a shaft end shows Thread must be at a shaft end, not between components; move it to an end to print.

The warnings banner

Above the carousel, a banner lists every problem on the shaft by the part's name, so none is missed when the card concerned is several swipes away:

  • overlaps first, one line per pair: FWD Liner overlaps Body size transition taper (these block printing);
  • parts running past the OAL: Body #1 runs 4 13/16" past the FWD end;
  • parts starting before the AFT end: AFT Thread starts 2" before the AFT end;
  • parts shorter than 1 mm: Body #2 is shorter than 1 mm.

Distances are in the drawing's unit. Tap a line (Show) to select that part: it is highlighted on the drawing and the carousel turns to its card. An overlap line selects the first part it names. With more than three problems the banner shows three and +N more; tap it for the rest. The drawing marks the same problems in red: the stretch two overlapping parts share, and the part of a component beyond the end, with the real end of the shaft dashed across it. Only overlaps block printing. Tap the ✗ (Dismiss warning) to hide the banner; it comes back if the set of problems changes.

Undo and redo

Tap History on the toolbar for Undo and Redo. Each is greyed when there is nothing to step to.

History covers the work on the shaft, on every tab of the job:

  • components added, edited and deleted, keyways, names, the overall length;
  • both drawings, the original and the Final schematic;
  • runout readings, runout bubbles you have dragged, and station counts;
  • wear marks and readings, and undercuts.

It does not cover project information, Settings, or the sheet sliders such as shaft height.

A quick burst of edits counts as one step, so undoing after typing a value takes you back to before you started typing, not one character at a time. History keeps the last 50 steps. It lasts for the editing session only: it is not saved with the file, and it starts fresh when you open, start or template a job.

History lives on the Schematic and Final Schematic toolbars. The Runout Sheet, Wear Document (and each component's wear page), Undercut Drawing and Consolidated Output tabs carry the same Undo and Redo as arrows in their top bar, so a reading, a bubble move or a worn section is undone where it was made. The Runout tab also has its own quick Undo move; see Recording Shop Measurements.

Templates

A template is a saved shaft shape: geometry without a job. Use one when the shop sees the same shaft again and again, so the next job starts with the tapers, liners and bodies already in place.

Saving a template

  1. Open the shaft you want to keep as a template.
  2. Open the save screen: tap More options → Save As… (or Save on a job that has never been saved).
  3. Tap Save as template….
  4. Check the Template name. It is suggested from the shape, for example “6in 3 liners A-M-F”; the line under it shows where the template will be filed, such as “Files under: 6″ liners · 3 liners”.
  5. Tap Save. The message Saved to templates confirms it.

If a template of that name exists, the app asks Replace existing template? before replacing it. Saving a template does not save or rename the job you are working on.

A template keeps the shaft's geometry only: components, their names, the unit and any per-component units. The job number, customer, vessel, item, notes, and every reading and measurement stay behind, as does any Final schematic.

Finding and using a template

Tap Start from Template on the home screen to open Templates. Templates are grouped twice:

  • by liner size, the largest liner OD (outside diameter) to the nearest inch: No liners first, then 4″ through 12″ (“6″ liners”), then Other sizes;
  • within each size, by liner count: 1 liner, 2 liners, 3 liners, 4+ liners.

Tap a heading to open it; any number of headings can be open at once, so you can compare templates from different groups. The number at the right of a heading is how many templates it holds. Each template card shows a drawing of the shaft, its name, its age, and a summary line such as “94 1/2″ OAL · Ø6″ max · 3 liners (A·M·F)”. The letters say where each liner sits, AFT to FWD: in the aft (A), middle (M) or forward (F) third of the shaft. Two templates with the same liner count can be told apart by this line alone.

Type in Search templates… to match names and summary lines; the groups give way to one list of matches. The Name and Date chips sort the list (tap the active chip again to reverse it).

  1. Tap the template card, or its ⋮ menu (Template options) → Use this template.
  2. If the current job has unsaved changes, choose Save, Don't save or Cancel.
  3. Fill in Project information for the new job.
  4. Adjust the dimensions to this shaft and tap Save.

The job opens as an unsaved, unnamed drawing, so the first save always asks for a name; the template itself can never be overwritten by a job made from it. The same ⋮ menu offers Rename and Delete. Deleting a template does not affect drawings already made from it.

The app comes with a few starter templates so the list is never empty on a new device. Settings → Data → Restore sample shafts separately puts the bundled example jobs back in your list of saved shafts.

Duplicate for mate

A twin-screw vessel has a PORT and a STBD (starboard) shaft that are nearly identical. Draw one, then make its mate from it.

  1. With the drawn shaft open, tap More options → Duplicate for mate…. (The same item is in each saved shaft's menu on the Open screen.)
  2. In Duplicate for mate, check Shaft Position. It is already flipped: PORT becomes STBD and STBD becomes PORT. Center and Other are left as they are.
  3. Check the Name. It is suggested from the job details with the new side, so “J-2214 - Acme Marine - PORT” proposes “J-2214 - Acme Marine - STBD”.
  4. Change Job Number, Customer or Vessel if the mate is billed differently.
  5. Tap Create.

The mate is written as a new saved shaft and the message Created ‘…’ confirms it. The shaft you were working on stays open, unchanged; open the mate from Open when you are ready to work on it. Create stays greyed if the name is blank or already taken (A drawing with that name already exists.), so a mate can never overwrite its twin.

Calculators and tools

Three shop calculators sit in the navigation menu under the document tabs. Each opens over the current screen, starts blank every time, and has its own Units chips (in | mm, starting on the job's unit). They read nothing from the shaft and write nothing into it: read the answer and type it where you need it.

Taper calculator

Taper calculator in the navigation menu opens Taper calculator, which solves the fourth value of a taper from any three:

  • Large end Ø (L.E.T.)
  • Small end Ø (S.E.T.)
  • Length
  • Taper rate, for example 1:12
  1. Enter three of the four values.
  2. Tap Calculate. The missing value appears in its own field, highlighted, so you can see it was worked out rather than typed.
  3. To use the answer as a starting point for the next question, tap the ✓ beside it (Keep calculated value as an input).

Enter all four values and Calculate checks them against each other. Change any entry and the old answer clears, so a number that no longer follows from the fields is never left on screen. Clear empties the fields; Close leaves. In inches, the rate is also shown in inches per foot.

Keyway calculator

Keyway calculator in the navigation menu opens Keyway rough-cutter depth, for roughing a keyway in a bore with a cutter narrower than the finished keyway. Enter Bore Ø, the finished Keyway width and Keyway depth, and up to two rough cutters (Cutter 1 width, Cutter 2 width). For each cutter it shows the depth to measure at the cutter's outer edges so its flat bottom lands on the finished keyway's floor. The answer updates as you type.

In inches, each depth is also given as a fraction for checking against a scale, to the nearest 64th, 32nd or 16th (the Scale chips, 64 by default).

Unit converter

Unit converter in the navigation menu opens mm ↔ in converter. Type a Value (fractions such as 1 1/2 are fine) in the unit chosen on the chips:

  • inches convert to millimeters, to three decimals;
  • millimeters convert to decimal inches, to four places, and to the nearest 64th, for example ≈ 1 31/64 in.

To reach the converter from inside an Add dialog, switch on Settings → Drawing → Unit converter in Add dialogs (off by default). A calculator icon (Unit converter) then appears in the title of every Add dialog. The converter shows its answer only; type it into the field yourself.

Editing the Final schematic

The Final Schematic tab uses this same editor, titled for the Final drawing, to record the shaft as it leaves the shop. Edits there never touch the original drawing, and edits here never touch the Final. Starting, resetting and printing the Final schematic are covered in The Final Schematic tab.
